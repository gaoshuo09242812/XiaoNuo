# 材料、接线与上电

参考 [材料表](bom.csv) 采购模块。固件目标为经典 ESP32、4 MB 闪存。不同开发板的排针位置不同，请按板上的 **GPIO 编号** 找引脚。信号分配以 [`pins.h`](../firmware/XiaoNuo/pins.h) 为准。

| 模块 | 模块脚 | 连接 |
| --- | --- | --- |
| 128×64 I²C OLED | SDA / SCL | GPIO21 / GPIO22 |
| OLED | VCC / GND | 支持 3.3 V 的模块接 3.3 V / GND |
| INMP441 | SCK / WS / SD | GPIO14 / GPIO27 / GPIO32 |
| INMP441 | VDD / GND / L/R | 3.3 V / GND / GND（左声道） |
| MAX98357A | BCLK / LRC（WS） / DIN | GPIO26 / GPIO25 / GPIO33 |
| MAX98357A | VIN / GND | 模块允许的 5 V 电源 / 共地 |
| 扬声器 | 两根线 | 分别接功放 `SPK+` 和 `SPK−` |

电源接法取决于开发板和模块的实际电路。确认开发板允许从 USB 提供 5 V 给功放后，再使用板上的 5 V 引脚。使用单独供电时要共地，并避免电源之间反灌。功放的两个扬声器输出都不接 GND。功放的增益和关断脚按所买模块说明处理。参考 [Analog Devices MAX98357A 数据表](https://www.analog.com/en/products/max98357a.html)。

1. 断电接线，核对电源正负、地线和短路情况。固定模块和喇叭，并给裸露焊点做绝缘。
2. 首次先检查开发板和屏幕，再接麦克风与功放。OLED 按模块实际控制芯片选 SSD1306 或 SH1106。
3. 第一次试听从低音量开始。遇到焦味、快速发热、冒烟或掉电重启，先断电检查供电和接线。
4. 日常用合规的 5 V USB 电源接开发板 USB 口，调试时换数据线接电脑。改接供电前先断开原电源。

按 [搭建指南](setup.md) 刷入固件并验证。数据线和扬声器线要固定牢固，裸板调试由成年人负责。
