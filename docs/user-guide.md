# 日常使用

1. 管理电脑开机、登录、联网，并运行小糯后台。手机打开已配置的 2.4 GHz 热点，放在设备附近。
2. 大人接好 5 V USB 电源，等屏幕出现两只眼睛。靠近麦克风说“小糯，你好”。等它说完，再问下一句。
3. 设提醒可以说“小糯，明天晚上八点提醒我整理书包”。听到“已保存”后核对时间。电脑里的“我的提醒”可修改、取消、设每天或每周重复。

| 屏幕或现象 | 先做什么 |
| --- | --- |
| 联网中 | 检查热点、移动数据和距离。换热点时按搭建指南重新配网。 |
| 连接中 | 检查管理电脑和中转。热点恢复后留时间自动重连。 |
| 识别中、准备回复、接收中 | 先等这一轮。较长回答可能等半分钟或更久。 |
| 有画面没声音 | 检查安静模式、发声开关和音量。 |
| 提醒没响 | 查电脑的提醒列表、时间和时区。小糯需联网且空闲，播放或断网会影响提醒。 |
| 进水、破损、发烫或焦味 | 孩子离远一点并叫大人。大人在安全条件下断开电源并检查。 |

声音和唤醒在电脑控制台“互动偏好”管理。开启电脑唤醒后，短音频经 TLS 和中转发送到电脑识别名字。普通无线对话的原始录音不保存，也不发给聊天模型。启用云端对话时会发送识别后的文字，相关记忆需同时取得全局与单条许可。聊天正文保存可在偏好里管理。请勿在对话里说密码、住址或电话号码。需要暂停叫名收音时关闭电脑唤醒，或由大人断开设备电源。

孩子负责说话和看屏幕，接线、供电和维护交给大人。重要提醒请由大人用适合的设备安排。付费模型的用量估算和预留可在控制台查看，实际费用以服务商账单为准。
